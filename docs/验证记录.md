SDK 测试使用项目的 get_client()，保留 timeout=45.0 和 max_retries=1，以 MockTransport 模拟通信结果并跳过退避等待。没有设置特殊重试覆盖响应头。

| 模拟情况 | 实际尝试次数与结果 |
| --- | --- |
| 首次超时，随后成功 | 2 次，返回模拟回答 |
| 持续超时或连接失败 | 2 次，抛出对应异常 |
| 普通 400、401、403 响应 | 1 次，抛出对应异常 |
| 持续 429 或 500 响应 | 2 次，达到上限后抛出异常 |

次数指单次 SDK 操作的传输尝试，不是整个问答的总请求数，也不是 Agent 的轮数。测试不验证真实网络恢复、退避耗时或模型回答准确率。[第 6 天结果](../验收数据/day6_tests.json)和[详细测试日志](../验收数据/day6_tests.txt)可用于核对。

## 原文与真实问答案例

- 使用文字型论文完成真实聊天、Embedding、导入与问答验收；无依据问题、重复导入、无效 PDF 和切换文件分别检查。
- 一次概括回答把 mAP 75.4% 归给 YOLOv8；人工核对原 PDF 第 9 页与相邻片段，确认属于 Faster R-CNN。固定字符切片导致词内截断已确认，尚未证明它是误归属的唯一原因。
- 检索后补充同论文同页邻居并去重，在模型回答前回填。第 9 页固定片段从 205 扩为 885 字符，方法名称和指标同时出现，数值未重复；第 3 页样本从 486 扩为 1166 字符，补回被截断的单词上下文。
- 针对 75.4% 的真实补问回答 Faster R-CNN，与原文核验一致。该补问与原概括问题分别记录，不作为相同问题前后对照或整体准确率提升的证明。
- 概括回答曾因模型使用带空白的引用编号而返回 citation_error；增加编号规范化后，仍拒绝未知或缺失引用。

扩展片段外侧仍可能断词，复杂版面和页脚仍可能影响内容。原始论文、数据库、完整回答与中间失败保留本地，不在本仓库提供。
